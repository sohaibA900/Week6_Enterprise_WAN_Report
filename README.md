Enterprise WAN Technologies and High Availability — Week 6
Overview

This project implements a multi-branch enterprise WAN in GNS3, connecting a Headquarters router (Islamabad) to four branch offices (Lahore, Karachi, and two additional sites) over authenticated point-to-point links. It layers PPP with CHAP authentication, GRE tunnels, OSPF dynamic routing, NAT/PAT for shared Internet access, and floating static routes for backup-path failover — a hands-on build of the technologies that keep a distributed enterprise network connected and resilient.
